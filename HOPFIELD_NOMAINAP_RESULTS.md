# Is position-modulated main attention necessary, given a Hopfield head?

`Level15_Hopfield_NoMainAP`: same as Level15_Hopfield, but the main
transformer attention gets identity rotation (pure content attention).
Position enters the model ONLY through the explicit Hopfield head.

This tests MapFormer's core design choice — entangled (position rotates
content attention) vs factored (position kept in a separate memory head,
TEM-style).

## Decision

- **NoMainAP ≈ Level15_Hopfield**: main attention's position channel is REDUNDANT once an explicit position-keyed memory head exists. Big finding — the factored (TEM-style) design is sufficient; MapFormer's entangled position-modulated attention was an unnecessary complication.
- **NoMainAP worse than Level15_Hopfield**: main A_P still contributes — entangled retrieval does something the obs-only Hopfield head can't.
- **NoMainAP worse than base Level15**: position-modulated main attention is load-bearing; the Hopfield head is a supplement, not a replacement.
