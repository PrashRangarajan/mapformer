Navigation told in words

The same walk on a torus, told as English prose with the moves buried among words that do not move anything. A one-layer path-integrating transformer finds the movement words by itself, learns that opposite directions cancel and that synonyms are one move, and reaches 0.969 on unseen maps, against 0.505 for an ordinary transformer of the same size.

Task 64×64 torus as prose, 58 wordsLength 1024 words (~132 moves)Seeds 8 per model, one batchStatus pre-registered

Why this experiment

In the MapFormer paper's navigation task the input strictly alternates action, observation, action, observation, …. Every action token is a move, so the model only has to learn the size of each move's step.

MapFormer's real claim is stronger. Every token gets a learned step, so the model should discover by itself which tokens move it and which do not. Strict alternation never tests that, because the moves sit in fixed slots. So we asked: if the same walk is told as prose, with the moves hidden among words that do not move anything, does path integration still work, and does the model find the movement words from the prediction task alone?

The task

The walk is the paper's 64×64 torus with 16 object types; half the cells are empty. Each move is written as a short clause:

[verb] [adverb?] [direction] [filler?] [seeing phrase] [object] .

walked slowly north then paused and saw a lamp . headed left and found nothing . she thought about a cat . went southward there was nothing .
direction words: the only words that move the object at this cell: what is predicted on a revisit an aside: names an object without placing it
  • Directions have three synonyms each: north / up / northward, south / down / southward, west / left / westward, east / right / eastward.
  • Verbs (walked, went, headed, …), adverbs (slowly, quickly, …), fillers (then, paused, looked around, …) and seeing phrases (and saw, and found, there was) do not move anything.
  • About 15% of moves are followed by an aside that mentions an object without a location.
  • 58 words in total. Each text is 1024 words, about 132 moves.
  • Direction words never appear outside a movement clause. That keeps a step that depends only on the word itself sufficient. "She thought about the north" is a separate problem.

What the model predicts: the object word each time the walk returns to a cell it has already visited, scored on a map it has never seen. It cannot memorise a map; it has to track where it is from the words.

Floors: what a model with no map can score

  • Always guess the commonest answer: 0.505 to 0.512, depending on the evaluation set.
  • Any pattern of up to 5 consecutive words: no better than that.
  • A reversal-copy rule: "if this move undoes the last one, copy the object from two moves back" scores 0.597. A model has to beat this to show it tracks position beyond immediate back-and-forth.

The models

Trained together in one batch, 8 seeds each, 900 epochs on 1024-word texts:

  • Path integration, 1 layer: MapFormer's working-memory model, step bottleneck of rank 4. Position is the running sum of a learned step per word.
  • Ordinary positional encoding (RoPE), 1 layer: position is the word's index.
  • RoPE, 2 layers: to see whether extra depth can substitute.

Did the model find the movement words?

A path model's step is a function of each word, so the whole map from words to moves can be read off as a step table: for each of the 58 words, how far and in which direction it moves the phase.

The pre-registered test

A seed passed if three things held together: non-movement words move less than 0.2× as much as direction words; opposite directions cancel (opposition score below 0.3, where 0 is perfect cancellation and 2 is none); and synonyms point the same way (cosine above 0.9). It passed on 4 of 8 seeds, short of the 6 required, so this readout landed in no registered branch.

Why the other four failed it

These follow-up readouts were declared before any batch result was read.

  • All 8 seeds learned a correct, cancelling map of the direction words. After removing one component shared by all four directions, north + south and west + east cancel to 0.002–0.012. Zeroing the direction words' steps drops every model to or below the floor (0.39–0.51): those words carry the position.
  • Synonyms collapse to one step on all 8 seeds (cosine 1.000).
  • The seeds split 4/4 between two solutions.

Map seeds (4)

Essentially all movement is on the direction words. The component shared by all directions is only 4–6% of a direction step.

2–4 of the 64 phase channels drift between visits to the same cell.

Clock seeds (4)

A large shared component, exactly aligned with the verbs' step (cosine 1.000): every move adds the same extra amount, so these models count moves as well as track place.

31–38 of the 64 channels drift between visits: about half carry the map, the rest carry time.

Clock seeds solve as well as map seeds. Whether a seed passed the criterion is unrelated to whether it solved (Fisher p = 1.00).

Corrections made later

Correction 1 · pilot seeds were in the batch

Seeds 0 and 1 turned out to be byte-identical to the pilot runs, so 2 of 8 seeds per model had been seen before registration. On the six fresh seeds alone: path 0.979 (6/6 solved) against RoPE 0.505 (0/6), +0.474, p = 0.0022. The verdict stands. Since then every pilot runs on seeds outside the batch.

Correction 2 · the clock is real

The clock was first described as equivalent to the map. Checking the drifting channels showed it is a genuine move counter, not a harmless reparametrisation.

Correction 3 · dropout re-score

Some path seeds had come to expect the rescaling that dropout applies to attention during training, so evaluating with dropout off understated them. Re-scored with that scale: path 0.969 → 0.993, RoPE unchanged, and the gap grows from +0.464 to +0.488.

What later work added

Asides: why "only action words move" is the wrong rule

In a later batch (NormStep on the text world), a reference model allowed to step only on the 12 direction words stopped at 0.972 on every seed. On the two seeds checked, every one of its errors (78 of 78, 89 of 89) named an object from an aside mentioned earlier at the same place. With no step on any other word, the aside's "cat" sits at that place's position. Learned-step models give each aside sentence a small net phase offset that moves the mentioned object elsewhere. After the dropout re-score, every learned-step model beats this oracle (0.994–0.997 vs 0.972, p = 0.0002). This finding is post hoc.

How a clock and a full map can coexist

The theory review (post hoc) found that the three solved clock seeds put their clock outside the directions used by the map, in channels that receive little attention weight. The one unsolved seed kept its clock inside the map's directions and lost a spatial axis. That fits the clock lemma: a clock and a full map can coexist only when the step map has a spare dimension.

What it shows, and what it does not

Shows

With the moves buried in prose, one path-integrating layer learns which words move it, that opposites cancel and that synonyms are one move, from the prediction task alone.

It beats an ordinary transformer with twice the layers by a wide margin.

Does not show

Natural language: the grammar is scripted, with 58 words, and direction words never appear in a non-movement sense.

Context-dependent steps, depth beyond 1–2 layers, or that RoPE can never do it: the RoPE models were still slowly improving at 900 epochs.

The next hard cases for a language cognitive map are words that sometimes move you and sometimes do not, named places that could replace path integration, and narration that is out of order.
