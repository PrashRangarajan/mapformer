# Cheapest experiments that close the biggest evidence gaps (ranked by decisiveness per GPU-hour)

Costs are from logged wall times of comparable past runs, as run-hours on a shared 4090
(concurrent jobs share a GPU, so wall time for a batch is lower):
- Dyck, paper budget (4375 steps): 65-76 s per run (`runs/dyck_ladder/*.log`).
- Torus T=128, 300 epochs: 2.8-7.7 s/epoch -> 15-40 min per run (`runs/paper2x2`, `runs/forget`, `runs/l15_ablation`).
- Torus T=1024 (batch 16), 900 epochs: 5.1 s/epoch -> ~77 min per run (`runs/rank_matched_e900`).
- Code at seq 2048, 36k iters: 8,051 s = 2.2 h per run; at 512 ~2.5 h (`runs/code2048`, `runs/code_decay`).
