## 1. 1D ring, per-head rank 1 vs 2 (plan 00_PLAN #3) -- ~1 h wall
- **Why first.** The cheapest test that can break the rank theory (T1: at per-head rank = D any step shared by all moves
  forces drift or collapse; at D + 1 a clock can sit off the map). On a ring D = 1: per-head rank 1 should fail, rank 2
  should solve. Rank 1 solving >= 6/8 kills T1 as stated.
- **Task.** `environment_cancel.py` (the H3 ring, 32 cells), symmetric walk p_plus = 0.5, T = 128, 300 epochs (CANCEL's
  recipe); 1 layer. CPU gate first: wrap-only revisit share on this stream (T5 says wrap-only revisits are what force the
  periodic code; if they are rare the test is about drift only, which is T1's claim).
- **Arms (n = 8, matched init within a seed).** per-head rank 1; per-head rank 2; rank 1 with drift forbidden
  (observation steps fixed at 0 and the +1 / -1 action steps tied to be exact negatives -- odd steps), the causal
  version of T1 on the cheapest task. 24 runs.
- **Code.** `train_cancel.py` takes only Vanilla / RoPE: add `--rank-per-head r` via `MapFormerWM_PerHead`
  (`model_rank_perhead.py`) and a drift-forbidden step module. Checks: the default path stays byte-identical to the stored
  CANCEL runs; the per-head module with one head equals the shared one at the same rank.
- **Decides.** T1 holds in 1D (r1 fails, r2 solves) / T1 broken (r1 solves) / drift-forbidden r1 solves (drift is the
  cause, not just the end state).

## 2. Rank escape test (plan #4) -- ~2.5-3 h wall
- **Why.** Distinguishes "search pathology at exact rank" (a spare rank lets a stuck model escape; Burer-Monteiro-type)
  from "the basin is chosen early" (a lifted model stays stuck). Uses the stored stalled rank-2 runs; no new long
  training.
- **Sources.** `runs/rank_mi/p0/Vanilla_s0-7` (shared rank 2, 0/8 SOLVED at T = 1024, 900 epochs, full state saved).
- **Arms per source (n = 8).** (E) lift to shared rank 4: two new W_in rows and W_out columns at small random scale, so
  the function is unchanged at step 0 (verify logits equal to ~1e-6); (C) continue at rank 2 with the same perturbation
  budget and schedule; (S) rank 4 from scratch for the same 300 epochs at the same seed (is "escape" just relearning?).
  300 epochs, 15-epoch warmup + cosine, lr 1e-3. 24 runs.
- **Decides.** E solves >= 6/8 while C <= 2/8 and E faster than S: escape (search pathology); E ~ C: basin chosen early;
  E ~ S: lifting only relearns. Pre-register "SOLVED iff a clean head" as a secondary only.
