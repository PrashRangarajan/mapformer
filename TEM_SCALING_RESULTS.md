## Decision

- **dg256 ≈ dg64 (saturated)**: TEM's task performance is NOT parameter-limited. The fixed Hopfield retrieval algorithm does the work; A_a only needs enough capacity to represent the action dynamics. Strong evidence for the inductive-bias account — TEM is parameter-efficient because the hard part (associative memory) is algorithmic, not learned.
- **dg256 >> dg64 (scales)**: TEM is merely under-parameterised at the default d_g; it would benefit from scale like any model.
- **dg32 << dg64 (underfit floor)**: locates the minimum d_g needed to represent the 4 action rotations.
