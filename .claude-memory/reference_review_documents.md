## Review structure (after a two-referee restructure)

frame → classification → classical relative methods → phase axis → magnitude axis →
one equation → **clock vs map** → relational map (+ four escapes, reported results) →
MapEM/TEM-t → memory reading → readout → **measurements** → choosing a mechanism →
conclusion → open questions → sources.

Measurements come BEFORE the synthesis that consumes them; that ordering was a
referee fix and should not be undone.

## Positioning, measured not asserted

Five surveys checked. Four have no content-dependent phase mechanism at all. The
fifth (Zhang et al. 2503.17407, Mar 2025) HAS the category — "content-aware position
embedding", members CoPE and DAPE — and predates almost everything in it.
**Do not write "no survey covers this."** That was in the review and was wrong.
The real point: the cell was opened on the ADDITIVE side (DAPE, CoPE, both 2024);
the multiplicative side filled in afterwards.
